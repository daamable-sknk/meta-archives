04  |  정보구조 재설계

아이템을 다시 정의하기

어떤 시스템이든 가장 작은 단위의 정의로부터 구조화가 시작된다. HTML 파일, PDF, 데이터셋처럼 형식은 달라도 물어야 할 질문은 같다.

더 이상 쪼개면 의미가 사라지는 최소 단위는 무엇인가.

서울연구데이터서비스 재구조화에서 이 질문에 먼저 답해야 했다. 기존 콘텐츠를 전수 분석하고, 연구 맥락 기준으로 목록을 만들고, 서울연구원과 합의하는 순으로 정의했다.

"아이템은 하나의 연구 목적·방법론·성과를 기준으로 독립적인 지식 단위로 정의되는 최상위 콘텐츠 묶음이다. 특정 연구 사업을 통해 생산된 결과물(보고서, 데이터셋, 시각화, 통계자료 등)을 포함하며, 단일 연구 과정에서 생성된 모든 산출물을 총괄하는 기본 단위로 사용된다."
(서울연구원과의 논의를 거쳐 확정)
관점 기존 아이템 정의 후
묶음 결과물이 형식별로 흩어짐 보고서·데이터·시각화가 하나의 아이템 아래 묶임
기준 신규 콘텐츠를 묶는 기준 없음 "같은 연구 맥락에서 생산된 자료인가"가 최우선 기준
산출 아이템 목록·계층 없음 ITEM TYPE 5개 · ITEM명 21개 (콘텐츠타입과 별도)
검색 관련 자료가 따로 노출 아이템 단위로 관련 결과물 일괄 접근

예: 서울도시기본계획 모니터링 2024 — 허브·리포트·세부 분석·PDF는 형식이 다르지만, 같은 연구 맥락이므로 하나의 ITEM명으로 묶는다.
