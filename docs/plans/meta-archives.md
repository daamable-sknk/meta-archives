# 비평 계획

## 개요

- 비평 대상은 [Are.na meta-archive](https://www.are.na/daehwan-jang/meta-archive) 채널에서 수집
- 순서 없이, 그때그때 관심이 가는 아카이브를 비평
- 연동 구조 및 동기화 방법은 [arena-sync.md](../arena-sync.md) 참조
- 점검·분류 논의: [meta-archive-inventory-review-2026-06-22.md](meta-archive-inventory-review-2026-06-22.md)
- 8축 관찰 YAML: [data/archives/](../../data/archives/)
- 경계 판별: [archive-boundary-criteria.md](archive-boundary-criteria.md)

### Are.na 동기화 현황

| 항목 | 값 |
|------|-----|
| 채널 블록 수 | **125** (Link 110 / Image 8 / Text 7) |
| 동기화일 | 2026-06-22 |
| API | `GET https://api.are.na/v2/channels/meta-archive?per=100` |

> 그룹 분류는 비평 우선순위 정리용 **1차 태그**다. 한 아카이브가 여러 그룹에 해당할 수 있으며, 다차원 매핑은 점검 문서의 8축 프레임을 따른다.
